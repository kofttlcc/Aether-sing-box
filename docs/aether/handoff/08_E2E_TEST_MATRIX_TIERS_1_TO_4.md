## 2. Logic Chain

1. **Pure Opaque-Box Isolation (`Obs 1`, `Obs 2`)**: Placing the E2E suite in `protocol/aether/e2e/*_test.go` under `package e2e_test` without importing `github.com/sagernet/sing-box/protocol/aether` (instead using `include.Context` + `json.UnmarshalExtendedContext[option.Options]` + `box.New` + compiled `sing-box` CLI binary) guarantees 100% opaque-box decoupling: tests compile against `M1`'s stub `option/aether.go` today and validate `M2`–`M5` implementations strictly via observable public behavior.
2. **Proving Wire & Cryptographic Contracts Without White-Box Imports (`Obs 1`, `Obs 2`)**: Interposing a deterministic loopback TCP `WireTapProxy` between the Client `box.Box` (`aether` outbound) and Server `box.Box` (`aether` inbound) — paired with a ~150-line **Spec Reference Wire Inspector/Crafter** implemented inside `harness_test.go` solely from the frozen math in `PROJECT.md § Interface Contracts` (using Go stdlib `crypto/*` and direct `golang.org/x/crypto/*`) — lets opaque-box tests observe and mutate raw TCP segments (`ClientSalt`, `MaskedClientEPK`, `EIH`, `96B`/`112B` prefix, `84B` `ServerResponsePrefix`, `18B` AEAD length headers, `Frame 0..5` padding/chunking, `Frame 6+` `PadLen=0` `<0.22%` overhead, zero `2-Byte` split segments, `FramePing`/`FramePong` jitter/padding, `FrameCloseWrite`, `0-len` chaff, `CommandUDP`, `ClientSalt` replay, bit-flip tampering, TCP half-open blackholes, and `3s..10s` `StealthDrain` TCP `FIN` vs `RST` timing) with zero internal symbol access.
3. **Zero `go.mod` Drift (`Obs 3`)**: Using `stretchr/testify/require`, `miekg/dns`, `runtime.NumGoroutine()`/`/proc/self/fd` leak checks (instead of `goleak`), a 30-line standard-library `.pcap` binary writer (`0xa1b2c3d4`, instead of `gopacket/pcapgo`), and standard-library/regex/`bash -n`/`python3` workflow validators (instead of `gopkg.in/yaml.v3`) preserves root `go.mod` and `go.sum` byte-for-byte.
4. **Fast, Parallel-Safe Execution Under `-race` (`Obs 2`)**: Cloning context per `Box` via `service.ExtendContext(baseCtx)` prevents `service.MustRegister` data races/panics; compiling `/tmp/.../sing-box` once in `TestMain`, using Base64 32B keys by default (reserving `Argon2id` passphrases for `F5`/selected combo tests), configuring `heartbeat_interval: "300ms"` (`PongTimeout = 500ms`) for DPD tests, using `ntp.TimeService` context offsets for instant clock jumps (`±29s`, `±35s`, `+61s`), and running `3s..10s` `StealthDrain` timing probes in parallel goroutines keeps total `-race` runtime under ~60s on 2 vCPUs.

## 5. Caveats

1. **Kernel-Level Raw Socket Capture (`AF_PACKET` / `tcpdump`) Unavailable in Unprivileged Sandbox**: As verified in `ci_and_test_survey.md:17`, the container has `CapEff=0000000000000000` and no `tcpdump` binary. Interposing `WireTapProxy` over real loopback `net.TCPConn` sockets (`TCP_NODELAY=true`) captures exact application-to-kernel `Write` syscalls and generates standard `.pcap` files deterministically without requiring `CAP_NET_RAW`.
2. **CPU Hardware Feature Flag (`AES-NI`) on Test Host**: On the Intel Xeon Platinum 8481C VM, `cpu.X86.HasAES && cpu.X86.HasPCLMULQDQ` is `true`, so `cipher: "auto"` deterministically selects `AES-256-GCM` (`0x01`) in opaque-box E2E runs (`T1-F09-03`), while `ChaCha20-Poly1305` (`0x02`) is verified via `cipher: "chacha20-poly1305"` (`T1-F09-02`). Simulating a non-AES CPU branch (`hasAES == false`) inside `"auto"` requires white-box helper injection in `protocol/aether/crypto_test.go` (`M2` / `M6` Tier 5), since `golang.org/x/sys/cpu` flags are process-global read-only variables from an opaque-box perspective.
3. **Parallel Execution of `E2E-Track` Against `M1` Shim**: Until `M2`–`M5` complete (`crypto.go`, `wire.go`, `conn.go`, `drain.go`, `inbound.go`, `outbound.go`, `upstream-sync-release.yml`), `protocol/aether/` still holds the `M1` v1.14.4 compile shim, so `protocol/aether/e2e/` will **compile cleanly** (`go test -c -race ./protocol/aether/e2e`) during `E2E-Track` (`TEST_READY.md`), while 100% runtime pass is gated in `M6` once `M2`–`M5` merge.
